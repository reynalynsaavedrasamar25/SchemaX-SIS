## SchemaX Installation Package

Unfortunately, we cannot upload the installers directly inside the folder due to the exceeding amount of MB required. Here's the guide to download them instead :)

1. Desktop Installer (Windows)

- "SchemaX.SIS.Setup.msi"
- "setup.exe"

Download both files from our GitHub Releases. Keep them in the same folder before running "setup.exe".

2. Mobile Installer (Android)

- "com.schemax.directory.apk"
- "SchemaX-SIS-Final-v2.apk"

Download the APK file and install it on a compatible Android device.
